## 硬约束

- 任何时刻只允许一套截屏采集服务运行（模块互斥 + 运行检测）
- 迁移期 ScreenMemo 独立 APK 保持可用；MCP 适配器接口不变，云端无感知切换
- 每步 PR 附：对照测试数据、署名/许可清单更新、回滚开关说明
